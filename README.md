### 04 // HOW I OPERATE

- **The WhatsApp Doctrine** — If an internal tool requires a new password or a 10-page onboarding deck, it is already dead. Ship where humans already live (WhatsApp, existing Slack, browser tabs).
- **The Eval-Before-Prompt Rule** — If you can't write down the pass/fail statistical criteria on paper, you don't have a product — you have an expensive slot machine.
- **The Grunt Work Principle** — Let agents digest the 3,500 contract clauses and reconcile the 150,000 ledger rows. Keep humans for taste, accountability, and the final 5%.
